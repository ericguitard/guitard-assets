# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities affecting this repository or
`assets.guitard.ca` privately by emailing [eric@guitard.ca](mailto:eric@guitard.ca).

Include the affected address or file, reproduction steps, expected impact, and
any supporting evidence. Do not include sensitive vulnerability details in a
public pull request, commit, or discussion.

Reports will be reviewed and handled according to severity and operational
availability. Please allow time for investigation and remediation before public
disclosure.

## Scope

Security reports may cover the published assets, custom error page, HTTP
security and caching headers, GitHub Actions workflows, GitHub Pages deployment,
or the Cloudflare-proxied production origin.
